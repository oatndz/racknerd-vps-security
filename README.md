## 你自己必须做的安全加固：6 步把 VPS 拧紧

VPS 给你的是完整 root 权限，这意味着安全的最后一公里在你手里。下面这套流程我自己每开一台新机器都会跑一遍，不复杂但管用。

1. **改掉 SSH 默认端口**：把 22 端口换成一个非标准端口，比如五位数。光这一步就能挡掉八成以上的自动化扫描爆破。
2. **禁用 root 直接登录，新建普通用户加 sudo**：root 账号是爆破首选目标，禁掉它改用普通用户提权，攻击面立刻小一截。
3. **SSH 改用密钥登录，关掉密码登录**：密钥比任何强密码都难撞，关掉密码登录后基本告别暴力破解。
4. **装 fail2ban 自动封禁可疑 IP**：连续登录失败几次的 IP 自动拉黑，省得你天天看 auth.log。
5. **配防火墙，只开必要端口**：用 UFW 或 Firewalld，默认只放行 HTTP/HTTPS 和你改过的 SSH 端口，其他全关。
6. **设置自动备份到异地**：用 rsync 把关键数据定时同步到另一台机器或者对象存储，这一步是底线中的底线——商家 RAID-10 只防硬盘坏，防不了你自己误删或者账号被盗。

讲真，前五步加起来不超过半小时，第六步要花点时间搭但一劳永逸。很多人觉得便宜 VPS 不安全，其实最大的漏洞不在商家，在自己没做这套基础加固。
